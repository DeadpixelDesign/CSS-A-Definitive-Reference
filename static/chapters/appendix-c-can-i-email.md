# Appendix C: Can I Email

This bibliography collects the sources used throughout the book. It is grouped by source type so readers can distinguish normative specifications, practical documentation, compatibility data, tutorials, tools, libraries, and production services. URLs are maintained as a living source trail; check the linked site for the current version before relying on a feature or service.

### Source maintenance note

The source list is intentionally broader than the minimum citations in each chapter. A source may provide background, an implementation example, a compatibility check, a design comparison, or a production workflow. Before a new edition, run link validation, remove dead or superseded links, record access dates for volatile sources, and preserve the source’s role in the relevant chapter notes.
