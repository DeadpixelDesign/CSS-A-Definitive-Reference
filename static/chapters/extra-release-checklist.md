# Extra: Release checklist

> **Editorial production note — omit from the published book.** This is the final working-manuscript extra for the author, editor, designer, and production team. Do not include it in the reader-facing print edition, EPUB, public PDF, or retail release unless the publishing plan explicitly calls for a release checklist.

Use this checklist after the manuscript, website, examples, and print files are otherwise complete. It is the final production gate, not reader-facing CSS instruction.

- [ ] Run link validation and replace dead links.
- [ ] Re-check every “new” feature against current MDN and Can I Use data.
- [ ] Render print and EPUB proofs; inspect table wrapping and code blocks.
- [ ] Test examples in at least Chrome, Firefox, Safari, and a mobile browser.
- [ ] Run accessibility review on the book website and examples.
- [ ] Confirm source attribution and licensing.
- [ ] Publish errata and compatibility updates outside the static book.
