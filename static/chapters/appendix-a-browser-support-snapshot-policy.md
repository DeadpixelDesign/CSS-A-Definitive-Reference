# Appendix A: Browser-support snapshot policy

This edition records a browser-support methodology rather than pretending that a printed book can remain current forever. At the time of editing, check the latest three versions of these ten desktop/mobile channels: Chrome, Edge, Firefox, Safari, Chrome Android, Safari iOS, Samsung Internet, Opera, UC Browser, and Android Browser. Record exact versions and the date of the check in the release notes. Use feature-level tables, not a single “CSS supported” score.

For a print edition, place a QR code beside this appendix that points to a maintained compatibility page. The print book should teach the decision process; the web page should carry the moving numbers.

### Can I Use: live browser compatibility

Use [Can I Use](https://caniuse.com/) to inspect feature-level support across current desktop and mobile browser versions. Search for the exact feature, read the notes for partial support and implementation caveats, and record the date of your review. The result is a decision aid, not a permanent guarantee.
